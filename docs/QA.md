# QA 체크리스트

출시 전에 한 번 훑는 목록입니다. 자동화된 항목은 스크립트 이름을 적어 뒀으니
직접 눌러볼 필요 없이 실행만 하면 됩니다.

```bash
export PATH="$HOME/.local/node/node-v24.19.0-darwin-arm64/bin:$PATH"
npm run build            # 타입 에러 0으로 통과해야 함
npm run test             # 밸런스 시뮬레이션
npm run dev              # 아래 headless 스위트는 dev 서버가 떠 있어야 동작
for s in flow recruit debut fandom album comeback results hub josa; do node scratch/$s.mjs; done
```

## 1. 빌드와 배포

- [x] `npm run build`가 TypeScript 에러 0으로 통과
- [x] 초기 JS 번들 300KB gzip 이하 — **96.7KB** (지연 로딩 후)
- [x] `dist/`를 하위 경로에서 열어도 자산이 깨지지 않음 (`base: './'`)

- [x] 팬덤 색을 바꾸면 응원봉 물결이 즉시 다시 칠해짐
- [x] 앨범 4단계에서 예산 슬라이더 합계가 항상 100%
- [x] 컴백 4주 — 슬롯 5개를 다 채워야 주차 종료 가능

## 4. 반응형

390px / 768px / 1440px 세 폭에서 확인. 자동 검사는 `scratch/audit.mjs`.

- [x] 가로 스크롤 없음 (`scrollWidth === clientWidth`)
- [x] 하단 바가 lg 미만에서 레일을 대체

- [x] 긴 한국어 문장이 단어 중간에서 끊기지 않음 (`word-break: keep-all`)

## 5. 접근성

- [x] 모든 인터랙티브 요소가 Tab으로 도달 가능
- [x] 포커스 링이 네온으로 항상 보임 (`:focus-visible`)
- [x] 아이콘만 있는 버튼에 `aria-label` (레일, 저장, 도움말, 카드 삭제)
- [x] 연습생 카드에 `aria-label="{이름} 연습생 상세 보기"`
- [x] 모달에 `role="dialog"` + `aria-modal` + Esc 닫기
- [x] 차트·아바타·관계도에 `role="img"` + 설명 `aria-label`
- [x] 흰 카드 위 보조 텍스트 대비 4.5:1 이상 (`text-ink/60`)
- [x] `prefers-reduced-motion`에서 애니메이션 정지
