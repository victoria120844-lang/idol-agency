# IDOL AGENCY SIMULATOR

**소형 기획사 운영 시뮬레이터.** 자본금 ₩5,000,000으로 시작해 연습생을 뽑고, 데뷔조를 짜고,
앨범을 내고, 4주간의 컴백을 버텨내는 싱글플레이 브라우저 게임입니다.

백엔드도 로그인도 API 키도 없습니다. 정적 파일 한 폴더면 어디서든 돌아갑니다.

---

## 배포

**한 줄 요약: `npm ci && npm run build` 후 나온 `dist/` 폴더를 정적 호스팅에 그대로 올리면 끝입니다.**

빌드 결과물은 상대 경로(`base: './'`)로 나오기 때문에 도메인 루트든 `/games/idol/` 같은
하위 경로든 수정 없이 동작합니다.

| 방법 | 하는 일 |
| --- | --- |
| Vercel | 저장소를 연결하면 `vercel.json`이 빌드 명령과 캐시 헤더를 알아서 처리합니다. |
| GitHub Pages | `main`에 푸시하면 `.github/workflows/deploy.yml`이 테스트 → 빌드 → 배포까지 돌립니다. 저장소 Settings → Pages에서 Source를 **GitHub Actions**로 한 번만 바꿔주세요. |
| 그 외 (Netlify, S3, 개인 서버) | `dist/` 폴더 업로드. SPA이므로 404를 `index.html`로 돌려주도록 설정하면 더 안전합니다. |

## 로컬 실행

Node 20 이상이 필요합니다.

```bash
npm ci
npm run dev      # 개발 서버 → http://localhost:5173
npm run build    # 타입 검사 + 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과를 로컬에서 확인
npm run test     # 밸런스 시뮬레이션 포함 전체 테스트
```

### 밸런스 시뮬레이션

```bash
npm run test:balance
```

시드 RNG로 200판을 끝까지 자동 플레이해서 종합 등급과 초동 분포를 출력합니다.
게임 규칙이 전부 `src/game/`의 순수 함수라서 DOM 없이 돌릴 수 있습니다.

## 기술 스택

| 영역 | 선택 |
| --- | --- |
| 빌드 | Vite |
| UI | React 18 + TypeScript |
| 스타일 | Tailwind CSS v4 (토큰은 `tailwind.config.ts`) |
| 상태 | Zustand + `persist` → localStorage |
| 애니메이션 | framer-motion |
| 라우팅 | 없음. `GameState.phase` 상태 기계 하나로 굴러갑니다. |

런타임에 나가는 네트워크 요청은 폰트 CDN 두 개(Pretendard, JetBrains Mono)뿐입니다.
그 외 모든 것은 번들에 포함되거나 시드에서 생성됩니다.

## 게임 흐름

```
intro → 기획사 설립 → 연습생 모집 → 데뷔조 결성 → 팬덤 설정
      → 앨범 제작 → 컴백 4주 → 결산 → 기획사 사무실
                        ↑                    │
                        └────────────────────┘
```

- **모든 무작위는 시드 RNG 하나**를 통과합니다. 시드와 커서가 세이브에 저장되므로
  같은 시드면 플레이가 그대로 재현됩니다.
- **관계는 게임의 중심**입니다. 데뷔 시 모든 멤버 쌍에 관계와 시작 이야기가 붙고,
  활동하며 매주 기록이 쌓입니다.
- **두 사이클 연속 적자면 폐업**합니다.
