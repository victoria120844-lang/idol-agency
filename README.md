# IDOL AGENCY SIMULATOR

**소형 기획사 운영 시뮬레이터.** 자본금 ₩5,000,000으로 시작해 연습생을 직접 뽑고, 데뷔조를 짜고,
앨범을 만들고, **7년 전속계약** 동안 몇 장을 낼 수 있는지 겨루는 싱글플레이 브라우저 게임입니다.

백엔드도 로그인도 API 키도 없습니다. **`index.html` 파일 하나가 게임 전부입니다.**

---

## 배포

**빌드가 필요 없습니다.** 이 저장소를 Vercel에 연결하면 `vercel.json`이 정적 배포로 처리합니다.

| 방법 | 하는 일 |
| --- | --- |
| Vercel | 저장소 연결만 하면 끝. 빌드 명령 없이 루트를 그대로 서빙합니다. |
| GitHub Pages | Settings → Pages → Source를 **Deploy from a branch / main / (root)** 로 지정. |
| 그 외 (Netlify, S3, 개인 서버) | `index.html`, `favicon.svg`, `og.png` 세 파일만 올리면 됩니다. |

> **Vercel 설정 확인**: 프로젝트 Settings → Build & Development Settings 에서
> Framework Preset이 **Other**, Build Command가 **비어 있음(Override 해제)**,
> Output Directory가 **`.`** 인지 확인하세요. 예전 React 설정이 남아 있으면 옛 버전이 배포됩니다.

## 로컬 실행

빌드도 설치도 필요 없습니다.

```bash
python3 -m http.server 8000    # → http://localhost:8000
```

`index.html`을 브라우저로 바로 열어도 동작합니다(저장은 localStorage를 씁니다).

## 게임 흐름

```
인트로 → 기획사 설립 → 연습생 모집 → 트레이닝 4주 → 데뷔조 결성
      → 앨범 제작 → 컴백 4주 → 정산 → 기획사 사무실
                                          ↑            │
                                          └────────────┘
```

- **연습생을 직접 등록합니다.** 이름·성별·나이·포지션(리더/메인보컬/서브보컬/메인댄서/서브댄서/래퍼/비주얼/올라운더). 사무실은 서울 8곳과 지방 3곳, 총 12곳 중에서 고릅니다.
- **앨범을 직접 구성합니다.** 싱글/미니/정규 중 선택, 수록곡 이름 입력, 타이틀곡 지정, 타이틀곡 파트 분배.
- **7년 계약.** 한 사이클이 6개월이라 최대 14장까지 낼 수 있습니다. 만료 시 재계약 또는 활동 종료.
- **성과는 누적됩니다.** 능력치·팬덤·인지도·자금이 다음 앨범으로 이어집니다. 화제성만 공백기에 사라집니다.
- **등급 기준은 상대적입니다.** 1집은 신인 기준선, 2집부터는 "지난 앨범 +18%"가 기준입니다.
- **사건이 터집니다.** 열애설·갑질논란·팬덤 분열·사생 문제·조공·광고 제의·연말 무대·라이벌 스캔들·컴백 충돌.
  선택에 따라 휴대폰에 옹호/비판 여론이 실시간으로 올라옵니다.
- **멤버끼리 관계가 있습니다.** 호감도가 오르면 같이 놀러 다니고, 임계를 넘으면 대표에게 면담을 신청합니다.

## 검증

```bash
export PATH="$HOME/.local/node/node-v24.19.0-darwin-arm64/bin:$PATH"
python3 -m http.server 8899 &          # 저장소 루트를 서빙
node scratch/deploy-check.mjs          # 전체 플레이 자동 검증
```

## 저장소 구조

| 경로 | 내용 |
| --- | --- |
| `index.html` | **게임 전부.** 단일 파일, 외부 의존성은 폰트 CDN 두 개뿐. |
| `favicon.svg`, `og.png` | 파비콘과 공유 이미지. |
| `vercel.json` | 정적 배포 설정(빌드 없음). |
| `scratch/deploy-check.mjs` | 헤드리스 전체 플레이 회귀 검사. |
| `legacy-vite/`, `src/`, `dist/` | 초기 React/Vite 프로토타입. **배포에 쓰이지 않습니다.** |
